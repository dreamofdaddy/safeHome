# SafeHome 합성 등기부 테스트 자료

모든 PDF는 실제 문서가 아닌 합성 테스트 자료이며, 각 페이지에 `테스트 전용 · 법적 효력 없음` 표시가 있습니다.

## 권장 테스트 순서

1. `http://localhost:5173`에서 회원가입 후 로그인합니다.
2. `매물 등록`에서 PDF 이름과 같은 시나리오를 선택합니다.
3. PDF 안의 `Frontend 등록 주소`를 주소 입력란에 그대로 입력합니다.
4. 아래 권장 거래 조건으로 등록합니다.
5. 상세 화면에서 `등기부 판독 시작`을 누르고 완료 상태를 기다립니다.
6. 판독 완료 후 `안전성 분석 시작`을 눌러 결과를 비교합니다.

## 시나리오

| 번호 | 파일 키워드 | 권장 거래 조건 | 확인 목적 |
|---|---|---|---|
| 01 | clean-single-owner | 전세 / 보증금 1억2천만원 | 단독 소유, 권리 제한 없음 |
| 02 | moderate-mortgage | 전세 / 보증금 8천만원 | 단일 근저당 |
| 03 | high-debt | 전세 / 보증금 2억5천만원 | 복수 근저당, 높은 채권액 |
| 04 | seizure | 월세 / 보증금 3천만원 / 월세 90만원 | 압류와 가압류 |
| 05 | co-owners | 매매 / 4억8천만원 | 공동 소유 |
| 06 | cancelled-rights | 전세 / 보증금 1억5천만원 | 말소 권리의 비활성 처리 |
| 07 | leasehold | 전세 / 보증금 1억6천만원 | 선순위 전세권 |
| 08 | complex-risk | 매매 / 5억2천만원 | 공동소유·근저당·가압류 복합 위험 |
| 09 | ownership-changes | 전세 / 보증금 1억원 | 과거 소유자를 제외한 현재 소유자 추출 |
| 10 | invalid-missing-required | 전세 / 보증금 5천만원 | 필수 식별정보 누락에 따른 실패 처리 |

## 판독 결과 해석

- 01~09는 판독 성공을 목표로 만든 문서입니다.
- 10은 `FAILED` 상태와 오류 표시를 확인하기 위한 의도적 실패 문서입니다.
- OpenAI 모델 결과는 확률적이므로 합성 서식을 처음 처리할 때 일부 필드가 다르게 추출될 수 있습니다.
- 실제 등기부 처리 품질 검증에는 개인정보를 적절히 보호한 실제 발급 문서가 별도로 필요합니다.

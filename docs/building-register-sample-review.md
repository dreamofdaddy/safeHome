## 최종 사용자 확정 기준 — 2026-10-22

집합건물의 건축물대장 파일 판독 신청은 **전유부 필수·표제부 선택·총괄표제부 선택**이다. 단독·다가구는 일반건축물대장을 받는다. 대장 점검 항목 자체는 선택이므로 전체 안전성 분석을 막지 않는다. 아래 '기본 확보 조합'은 이전 검토 과정의 권장안이며 최종 첨부 필수 규칙은 이 절과 [파일 판독 계약](building-register-pdf-flow.md)의 최신 절을 따른다. 실제 샘플의 사건별 해제·중복 관련 기대 결과는 검증 기준으로 보존한다.

# 건축물대장 샘플 검토 및 첨부 범위 기준

검토일: 2026-10-22. 사용자 제공 아파트·빌라 PDF 4개, 총 9페이지를 로컬 텍스트 추출 및 관련 표·변동사항 영역의 이미지로 확인했다. 외부 OpenAI·공공 API를 호출하지 않았다. 이 검토는 문서 종류·필요 범위를 정하기 위한 것이며 운영 AI 판독 품질 시험이나 문서 진위·현장 위반 판정이 아니다. 실제 PDF·추출 원문·소유자 개인정보·주소·식별번호는 저장소에 넣지 않는다.

## 추가 자료 확인 — 아파트 해당 동 표제부

초기 4개 샘플 검토 후 아파트 표제부 PDF 3페이지가 추가 제공됐다. 실제 제목은 집합건축물대장(표제부, 갑)이며 해당 건물의 전체 층수·층별 구조/용도/면적과 2~3페이지 변동사항을 확인했다. 따라서 제공된 문서 종류는 아파트의 총괄표제부·표제부·전유부와 빌라의 표제부·전유부로 갖춰졌다. 문서 대상 관계의 자동 검증이나 외부 AI 판독을 완료한 것은 아니다. 아래의 아파트 표제부 미제출은 추가 제공 전 초기 검토 기록이다. 전유부와 해당 동 표제부의 역할을 구분하고 총괄표제부는 보완 자료로 두는 기준을 유지한다.

## 1. 확인한 문서 구성

| 사례 | 문서 | 분량 | 확인 범위 |
|---|---|---|---|
| 아파트 A | 총괄표제부 갑·을 변동사항 | 3페이지 | 여러 건축물의 전체 현황 및 총괄 이력. 해당 동 표제부와 구분 |
| 아파트 A | 전유부 갑·뒷면 | 2페이지 | 특정 호실 전유부분, 공용부분, 변동사항 및 그 밖의 기재사항 |
| 빌라 B | 표제부 갑·뒷면 | 2페이지 | 해당 건물의 구조·층수·층별 용도/면적과 변동사항 |
| 빌라 B | 전유부 갑·뒷면 | 2페이지 | 해당 호실의 층·구조·용도·전유면적과 공용·변동사항란 |

아파트 A는 총괄표제부와 전유부가 제출됐으며 해당 동 표제부는 이번 자료에 없다. 빌라 B는 해당 건물 표제부와 전유부가 함께 제출됐다. 파일명이나 본문에 '총괄표제부'라는 단어가 등장하는 것만으로 종류를 판정하면 안 된다. 표제부 하단 공통 안내에도 그 단어가 있으므로 실제 제목·서식·구획을 기준으로 구분한다.

## 2. 개발 기준 결정

1. 아파트·다세대·연립 등 집합건물에서 전유부는 호실 단위 점검의 기본 자료다. 단독 제출·판독을 허용한다.
2. 건물 단위 문서 점검에는 **해당 동 표제부도 필요**하다. 전유부만 있으면 호실의 제공 자료 범위만 확인하고 건물 단위 범위는 미확인으로 둔다. 이 필요성은 SafeHome의 점검 범위 기준이며 법정 필수 제출 의무를 뜻하지 않는다.
3. 총괄표제부는 단지·대지의 여러 건물 관계를 확인하는 선택 보완 자료이며 해당 동 표제부를 대신하지 않는다. 단지 전체 면적을 특정 호실의 면적과 직접 비교하지 않는다.
4. 각 문서는 앞면만이 아니라 뒷면·추가 장·변동사항을 포함해 발급받은 전체를 받는다. 아파트 샘플에는 총괄표제부 을 추가 장이 실제 포함되어 있었다.
5. 단독·다가구 등 일반건축물에는 일반건축물대장을 안내한다. 집합건물 전유부 제출 규칙을 일률 적용하지 않는다.
6. 건축물대장은 선택 점검 항목이다. 미첨부·일부 첨부·판독 실패여도 등기사항 기반 안전성 분석을 막지 않고 미확인 범위를 표시한다.
7. 전유부와 표제부를 받았다는 사실만으로 건물의 적법성·현장 일치·미등기 없음이 확정되지 않는다. 표제부에 표시가 있어도 해당 호실의 위반으로 자동 귀속하지 않고 대상·위반 내용·기준 시점 확인이 필요하다.

## 3. 판독·비교에 반영할 주의점

- 전유면적, 공용부분 면적, 층별 면적, 건축면적, 연면적, 용적률 산정용 연면적을 각각 구분한다. 표제부의 층별 면적은 해당 호실 전유면적과 항상 같아야 하는 값이 아니다.
- 전유부의 공용부분에 지하층이 나와도 해당 호실이 지하라는 뜻이 아니다. 해당 호실의 층은 전유부분을 기준으로 한다.
- 샘플에는 일부 대지면적·비율이 0으로 인쇄되어 있다. 이를 곧바로 실제 대지 없음·위반·누락 위험으로 판정하지 않고 자료 의미와 기재 범위를 확인한다.
- 신규작성·지번 정정·행정구역 명칭 변경·기초자료 정비가 있었다. 변동사항이 존재한다는 이유만으로 위반·증축·용도변경을 확정하지 않는다. 단순 정비의 전후 수치 변화를 실제 공사로 단정하지 않는다.
- 현재 위반 표시, 현재 위반 관련 기재, 과거 위반 및 시정·말소 이력을 구분한다. 샘플 제공 페이지에서 위반 표시·위반 관련 문구는 확인하지 못했으나 위반 없음·진위·현장 적법성의 확인은 아니다.
- 건물 전체·층·호실의 표기와 공용부분을 구분하고, 제목/서식으로 문서 종류를 분류해야 한다. 여러 문서의 대상 관계와 시점이 맞는지도 별도 확인해야 한다.

## 4. 현재 구현 및 후속 적용

현재 전유부 단독 업로드 허용, 표제부 추가 권장, 표제부 미첨부 범위 안내, 총괄표제부 종류 구분, 전체 PDF 업로드·이력 보존 기능이 있다. 이 검토에서는 소스코드·DB·서버 상태를 변경하지 않았다.

후속 구현에는 문서별/구획별 항목 구조, 면적 종류·층·구조·관리번호 관계·시점 비교, 누락된 장 인식 및 선택적인 표제부 추가 안내가 필요하다. 이를 아직 구현된 비교 기능이나 실제 AI 품질 검증으로 보고하지 않는다. 불완전한 공공 API의 일부 정보만으로 문서 변동사항 전체를 확인했다고 처리하지 않는다.

공식 근거: [건축물대장의 기재 및 관리 등에 관한 규칙 제8조](https://www.law.go.kr/lsLinkCommonInfo.do?lspttninfSeq=105390)는 위반 표시와 변동사항 기재·시정 시 표시 삭제를 구분한다. 제품상 첨부 정책과 법적 판정은 구분한다.

## 5. 실제 위반 표시 샘플 추가 검토 — 2026-10-22

사용자 제공 샘플 05·06의 표제부·전유부 4개 PDF, 총 9페이지를 로컬에서 확인했다. 개인정보 영역을 제외한 표·위반 표지·변동사항을 텍스트와 이미지로 검토했다. 외부 AI·공공 API 호출과 애플리케이션 판독 검사는 실행하지 않았다.

### 샘플 05: 건물과 호실에 모두 위반 표시가 있는 경우

- 표제부 2페이지: 첫 장에 현재 위반 표시가 있으며 뒷면에는 여러 호실의 무단증축 기재가 있다.
- 전유부 2페이지: 첫 장에도 현재 위반 표시가 있고 뒷면에는 해당 401호의 주거 4㎡ 무단증축 기재가 있다.
- 테스트 기대: 해당 호실의 4㎡와 표제부에 나열된 다른 호실의 면적을 구분한다. 다른 호실의 위반을 대상 호실에 합산하지 않는다. 표제부와 전유부에 중복 기재된 동일 사건을 두 번 산정하지 않는다.

### 샘플 06: 전유부에만 위반 표시가 있고 일부 사건에 해제 이력이 있는 경우

- 표제부 3페이지: 제공된 페이지에서 위반 표지·위반 관련 기재는 확인하지 못했다. 세 번째 페이지는 표제부 을의 건축물현황 추가 장이다.
- 전유부 2페이지: 첫 장에 현재 위반 표시가 있다. 뒷면에는 2018-08-28의 6층 판넬 구조 약 8㎡ 관련 표기, 2019-01-14의 옥상 무단증축 0.6㎡ 관련 표기, 2020-08-14의 2019-01-14 사건을 특정한 표기 해제가 있다.
- 테스트 기대: 문서 요약은 '첨부 전유부에 위반 표시 있음 · 일부 표기 해제 이력 있음'으로 표현한다. 2020년 해제는 문구가 참조하는 2019년 사건에 연결하며 모든 사건 해제로 확대하지 않는다. 2018년 사건에 대한 해제 기재는 이 제공 문서에서 확인하지 못했다는 범위를 보존한다.
- 표제부에 표시가 없다는 이유로 전유부의 표시를 덮어쓰지 않는다. 두 문서의 표시 차이만으로 주소·대상 불일치나 파싱 오류라고 단정하지 않는다. 대상·기준시점·문서 범위를 별도로 대조해야 한다.

### 확정한 첨부·판독 기준

1. 집합건물의 기본 확보 조합은 대상 전유부와 해당 동 표제부다. 전유부만으로 호실 범위 판독을 허용하며 표제부 누락 범위를 알린다. 총괄표제부는 추가 보완 자료다. 건축물대장 항목 전체는 여전히 선택 항목이다.
2. 앞면의 표지와 뒷면·추가 장의 기재를 모두 읽는다. 표제부만으로 개별 호실의 위반 관련 점검을 완료하지 않는다.
3. 현재 문서 표지, 사건별 표기/해제 이력, 다른 호실의 사건을 구분한다. 문서상의 현행 표시와 해제 문구가 충돌하거나 사건 연결이 모호하면 추가 확인으로 둔다.
4. 해제 이력이 있더라도 현재 표지가 남아 있으면 단순 '위반 없음'으로 표시하지 않는다. 한 사건의 해제는 다른 사건에 자동 적용하지 않는다. 두 면적을 더해 현재 위반 면적을 산출하지 않는다.
5. 현재 구현은 표지·관련 문구·근거 페이지를 추출하고 표시하는 1차 범위다. 사건별 구조화·부분 해제 연결·다른 호실 분리·사건 중복 제거의 정확성은 추가 구현 및 회귀 검증 대상이다. 실제 AI가 이 샘플을 정확하게 판독했다고 보고하지 않는다.

위 기대 결과는 문서 기반 테스트 기준이며 현재의 법적 위반 상태나 현장 상태를 확정하는 결과가 아니다. 실제 원본 PDF는 외부 데이터 폴더에 유지한다.

- 표제부 4페이지와 전유부 3페이지의 앞면 모두에 위반건축물 표시가 있다.

- 표제부에는 별도로 2022-06-20 지상 1층 대기주차장 1면 기능 미유지 기재와 그 사건을 특정하는 2022-12-28 해제, 2024-01-08 조경면적 미확보 약 51㎡ 기재가 있다. 전유부에 없는 이 내용을 대상 호실의 전유부분 위반으로 자동 귀속하지 않고 건물 범위의 별도 확인 항목으로 알린다.
- 주차장 사건의 해제를 옥상·조경 사건에 확장하지 않는다. 단순히 가장 나중 날짜의 기재를 전체 위반 상태로 채택하지 않는다.
- 표제부 일부 해제 문장은 2페이지에서 4페이지로 이어지고, 전유부 일부 해제 문장은 2페이지에서 3페이지로 이어진다. 가운데에 건축물현황 추가 장이 있거나 한쪽 구획에 '이하 여백'이 있어도 파일 전체를 읽어야 한다. 다음 장의 날짜 없는 문장을 앞선 같은 기재의 연속으로 연결하되 연결이 모호하면 확인 필요로 둔다.
- 기대 요약: '첨부 문서에 위반 표시 있음 · 일부 시정/해제 이력과 미시정 기재가 함께 있음'. 사건별 시정/미시정 기재와 근거 페이지를 분리한다. 현장 현재 상태나 법적 확정 판정으로 바꾸지 않는다.
